# When2Meet

주별 고정 일정을 제외하고 링크로 가능한 시간을 모으는 한국어 일정 조율 서비스입니다. 시간은 한국 표준시이며 30분 단위입니다.

약속 길이는 지정하지 않습니다. 가능한 참여자가 동일한 연속된 시간을 묶어 보여주며, 예전 약속에 저장된 길이도 결과를 제한하지 않습니다. 기존 데이터와 이전 버전의 호환성을 위해 데이터베이스의 `duration` 열은 유지하지만 새 약속에는 사용하지 않는 값 0을 저장합니다.

시간표는 최대 14일 전체를 나란히 표시합니다. 가로세로 드래그한 사각 영역을 칠하거나 지울 수 있고 고정 일정은 항상 건너뜁니다. 모바일에서는 기본적으로 스크롤과 탭을 사용하고, ‘드래그로 칠하기’를 켜면 손가락으로 영역을 선택합니다. 가장자리에서는 시간표가 자동으로 스크롤됩니다. 방향키와 Space 선택도 지원합니다.

## 실행

Node.js 24 이상을 권장합니다. 별도의 실행 의존성 설치 없이 `npm run dev`를 실행하고 http://127.0.0.1:4173 을 엽니다. 계정과 일정 데이터는 `.local/when2meet.sqlite`에 저장됩니다. `npm test`는 인증, 일정 계산과 API 보호 동작을, `npm run build`는 기존 Worker 호환 빌드를 검증합니다.

## 회원과 공유

자체 Node 서버에서는 이름·이메일·비밀번호로 가입하면 바로 로그인됩니다. 이메일 인증이나 메일 발송 서비스는 필요하지 않습니다. 비밀번호는 12~128자이며 무작위 솔트와 scrypt(N=32768, r=8, p=3)로 해시합니다. 로그인 세션은 무작위 토큰의 해시만 서버에 저장하고, 브라우저에는 HttpOnly·SameSite=Lax 쿠키를 사용합니다. HTTPS 운영에서는 Secure와 __Host- 접두사도 적용됩니다. 계정과 접속 주소별 시도 제한, 동시 해시 처리 제한, 출처 검사도 적용합니다.

이메일 주소는 소유 여부를 검증하지 않는 로그인 식별자입니다. 이메일을 통한 비밀번호 재설정이나 계정 복구는 제공하지 않습니다. 기존 ChatGPT 계정과 이메일이 같더라도 자동으로 계정을 연결하거나 기존 일정의 소유권을 넘기지 않습니다.

생성된 `/m/<id>` 링크는 같은 서버의 저장된 약속을 엽니다. 참여자는 자체 회원가입이나 로그인 후 응답할 수 있습니다. 기존 ChatGPT Sites 배포본은 별도 서비스이며, 자체 계정의 공개 서버로 사용할 수 없습니다.

고정 일정의 이름과 시간은 계정 소유자만 조회합니다. 약속 링크를 가진 로그인 사용자는 약속 제목, 날짜, 참여자 표시 이름과 가능 시간 집계를 볼 수 있습니다. 새 고정 일정은 이미 제출한 응답 집계에서도 제외되며, 삭제된 고정 일정의 시간은 참여자가 다시 선택해 제출해야 합니다.

수정 요청은 서버에서 본인 계정으로 제한하고, 다른 사이트에서의 쓰기 요청을 차단합니다. 고정 일정과 응답은 버전 확인으로 다른 창의 변경 사항을 덮어쓰지 않습니다. 시간 선택이 저장되지 않은 상태에서 나가면 브라우저가 확인을 요청합니다.

## 검사

`tests/browser.mjs`는 Puppeteer Core와 Chrome 경로를 환경 변수로 전달해 실행합니다. 두 자체 계정으로 이메일 인증 없는 가입, 생성한 링크 접속, 참여 저장, 반복 일정 변경, 키보드 선택, 모바일 화면을 검사합니다. `tests/auth.test.mjs`는 중복 이메일, 비밀번호 해시, 세션 만료·폐기, 시도 제한, 출처 검사와 외부 인증 헤더 위조 차단을 검사합니다.

## 배포

### GitHub Pages

공개 주소: https://0verhydrated.github.io/when2meet/

`main`에 소스를 올리면 `.github/workflows/pages.yml`이 테스트와 `npm run build:pages`를 실행하고 `pages-dist/`를 배포합니다. 별도의 패키지 설치나 배포용 비밀키는 필요하지 않습니다. 저장소 변수 `PUBLIC_SERVICE_ORIGIN`에 자체 서버의 HTTPS 원점(예: `https://when2meet.example`)을 지정하면 가입과 일정 기능이 해당 서버로 연결됩니다.

GitHub Pages는 계정 정보를 저장하거나 인증 API를 실행할 수 없습니다. 자체 서버가 설정되지 않으면 ChatGPT로 이동하지 않고 가입·로그인 화면에 서버 미연결 상태를 표시합니다. 이 상태에서는 입력과 제출을 비활성화하며 계정을 만들었다고 표시하거나 비밀번호를 브라우저 저장소에 보관하지 않습니다. 실제 회원가입을 받으려면 아래 서버 배포가 필요합니다.

### 자체 회원가입 서버

HTTPS와 영구 저장 공간을 제공하는 Node 또는 Docker 호스팅에 배포합니다. SQLite 파일이 유지되지 않는 일반 서버리스 임시 파일 시스템에는 배포하지 않습니다. 환경 변수는 `.env.example`을 참고하며 Node에 직접 전달합니다.

```
NODE_ENV=production PUBLIC_ORIGIN=https://your-when2meet-server.example DATABASE_PATH=/data/when2meet.sqlite PORT=3000 npm start
```

Docker에서는 `docker build -t when2meet .`로 빌드하고 `/data`에 영구 볼륨을 연결합니다. HTTPS 종료는 호스팅의 프록시에서 처리하며 `PUBLIC_ORIGIN`은 사용자가 실제로 접속하는 정확한 HTTPS 원점이어야 합니다. 서버 시작 시 기존 데이터를 유지하면서 아직 적용되지 않은 마이그레이션만 트랜잭션으로 적용합니다. 운영자는 데이터 파일을 백업해야 합니다.

### 기존 서버

`.openai/hosting.json`의 `DB` D1 바인딩과 `drizzle/` 마이그레이션을 포함해 배포합니다. `npm run build`는 정적 파일을 포함한 `dist/server/index.js`를 생성합니다. 서버 실행 중 테이블을 생성하거나 변경하지 않습니다.
