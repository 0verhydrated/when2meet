# When2Meet

주별 고정 일정을 제외하고 링크로 가능한 시간을 모으는 한국어 일정 조율 서비스입니다. 시간은 한국 표준시이며 30분 단위입니다.

## 실행

Node.js 22.13 이상이 필요합니다. 별도의 실행 의존성 설치 없이 `npm run dev`를 실행하고 http://127.0.0.1:4173 을 엽니다. 로컬 데이터는 `.local/when2meet.sqlite`에 저장됩니다. `npm test`는 일정 계산과 API 보호 동작을, `npm run build`는 배포용 Worker를 검증합니다.

## 회원과 공유

배포 환경에서는 Sites의 ChatGPT 인증을 사용하고, 첫 로그인 후 이름을 등록하면 가입됩니다. 로컬 미리보기는 같은 화면 흐름을 확인하기 위한 개발용 인증을 사용합니다. 이메일·비밀번호 가입, 이메일 인증, 비밀번호 찾기는 제공하지 않습니다.

생성된 `/m/<id>` 링크는 같은 서버의 저장된 약속을 엽니다. 참여자는 로그인과 이름 등록 후 응답할 수 있습니다. 새 Sites는 기본적으로 소유자 비공개입니다. 다른 사람이 배포 링크에 접속하려면 Sites에서 해당 사람에게 접근 권한을 부여하거나 서비스 공개 범위를 변경해야 합니다.

고정 일정의 이름과 시간은 계정 소유자만 조회합니다. 약속 링크를 가진 로그인 사용자는 약속 제목, 날짜, 참여자 표시 이름과 가능 시간 집계를 볼 수 있습니다. 새 고정 일정은 이미 제출한 응답 집계에서도 제외되며, 삭제된 고정 일정의 시간은 참여자가 다시 선택해 제출해야 합니다.

수정 요청은 서버에서 본인 계정으로 제한하고, 다른 사이트에서의 쓰기 요청을 차단합니다. 고정 일정과 응답은 버전 확인으로 다른 창의 변경 사항을 덮어쓰지 않습니다. 시간 선택이 저장되지 않은 상태에서 나가면 브라우저가 확인을 요청합니다.

## 검사

`tests/browser.mjs`는 Puppeteer Core와 Chrome 경로를 환경 변수로 전달해 실행합니다. 두 개발용 계정으로 가입, 생성한 링크 접속, 참여 저장, 반복 일정 변경, 키보드 선택, 모바일 화면을 검사합니다. 실제 ChatGPT 인증 제공자의 로그인과 외부 참여자의 접근 권한은 별도 실제 계정으로 확인해야 합니다.

## 배포

`.openai/hosting.json`의 `DB` D1 바인딩과 `drizzle/` 마이그레이션을 포함해 배포합니다. `npm run build`는 정적 파일을 포함한 `dist/server/index.js`를 생성합니다. 서버 실행 중 테이블을 생성하거나 변경하지 않습니다.
